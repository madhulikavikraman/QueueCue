# QueueCue AI prompts

Generated by `dart run bin/dump_prompts.dart` from `server/lib/ai/prompts/` and `server/lib/ai/schemas.dart`. Do not edit by hand.

Every call goes to the local Ollama model (`qwen3:14b`, set in `server/config.json`) with the JSON schema in the `format` field (structured output). The server validates the response against the schema, retries once with the validation errors, then falls back to the cached or offline result with a visible notice.

## How the pitch is made

1. **Voice Profile** (`voice_profile`, once at onboarding) from the 60-second recording (whisper.cpp, on the laptop) and 2 typed answers.
2. **Pitch Facts** (`pitch_facts`): 1-2 relevant projects with the detail that makes them real, one connection to a listed role, one booth-specific question.
3. **Draft** (`pitch_draft`): 55-80 words in the student's voice + question + 2 talking points + a sentence-by-sentence source trace.
4. **Critic** (`pitch_critic`, separate prompt) plus a deterministic lint that cannot be skipped. Rewrite (`pitch_rewrite`) if anything fails or any score is below 4. Max 2 rewrites.
5. Student controls: More like me / Shorter / Different project / Edit. Edits are stored on the Voice Profile and fed into future drafts.

Fit scoring (`booth_fit`) runs **twice** with the role list in two different orders and averages the result. Resumes are blinded first (name, email, phone, links, pronouns, years/dates, addresses removed).

## Shared grounding rules (inserted into every prompt)

```text
GROUNDING RULES (apply to every answer):
- Use only facts present in the student's resumes, Voice Profile and the employer data given below.
- If something is unknown, write "unknown". Never invent numbers, titles, employers, awards, dates or company facts.
- Never use or infer name, gender, age, ethnicity, nationality, photo, school year, or any protected attribute.
- Output JSON only, matching the provided schema exactly.
```

## Banned words and phrases (critic + deterministic lint)

`passionate`, `leverage`, `synergy`, `cutting-edge`, `cutting edge`, `innovative`, `dynamic`, `results-driven`, `thrilled`, `excited to`, `i'd love to`, `i would love to`, `i've always been fascinated`, `i have always been fascinated`, `deeply`, `unique opportunity`, `aligns perfectly`, `valuable`, `world-class`, `revolutionize`, and any "As a ___ student" opener.
